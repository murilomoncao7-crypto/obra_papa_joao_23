# Obra Papa João XXIII

Nome provisório do projeto institucional da Obra de Assistência Social Papa João XXIII.

## Finalidade

Este repositório preserva e organiza o site institucional da entidade. Informações institucionais devem ser confirmadas com a própria instituição antes de serem adicionadas ou alteradas.

## Versao atual

A versão inicial é um site estático desenvolvido com HTML, CSS e JavaScript nativos, acompanhado de seus arquivos de imagem.

## Migração planejada

O projeto será reconstruído futuramente com Next.js e TypeScript. Essa migração deve ocorrer de forma incremental, sem apagar ou descaracterizar a versão estática preservada.

## Preservação da versão antiga

A versão estática original está registrada no primeiro commit do histórico Git e identificada pela tag anotada `legacy-static-v1`. Ela funciona como ponto de restauração anterior à migração.

## Seguranca

Credenciais, tokens, chaves privadas, senhas e arquivos de ambiente não devem ser versionados. Use arquivos locais de ambiente e mantenha apenas exemplos sem valores secretos quando necessário.
